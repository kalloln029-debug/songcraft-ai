# SONGCRAFT AI
Turn any feeling into a song-ready blueprint.

## Setup
1. Install Node.js 18+
2. Run `npm install`
3. Copy `.env.example` to `.env` and add your `OPENROUTER_API_KEY`
4. Update `firebase-config.js` with your Firebase credentials
5. Run `npm start`
6. Open http://localhost:3000

## Deploy to Vercel
1. Push the project to GitHub
2. Import the repository in Vercel
3. Add `OPENROUTER_API_KEY` as an environment variable
4. Deploy

## Firebase Setup
- Enable Google, Microsoft, and Apple sign-in providers in Firebase Console
- Add your local and Vercel domains to Authorized Domains
- Configure each provider's credentials and callback settings in Firebase Console
